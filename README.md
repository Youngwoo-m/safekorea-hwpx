# safekorea-hwpx

`safekorea-hwpx`는 안전한국훈련의 기본계획, 실행계획, 통합시나리오, 컨설팅보고서, 평가보고서를 작성·검토하고 위기관리 매뉴얼과의 정합성을 확인하기 위한 Codex 스킬입니다.

## 주요 기능

- 해당 연도 가이드북·평가지표 기반 문서 작성
- 위기관리 표준·실무·행동매뉴얼과 훈련문서 정합성 검토
- 기본계획서 → 실행계획서 → 통합시나리오의 연계 작성과 정합성 매트릭스 생성
- 정량적 훈련목표와 증빙자료 설계
- 기존 HWPX 서식 보존 및 붉은색 변경표시·메모
- 개인정보와 기관 고유정보 비식별화
- 한컴오피스 실제 열기와 렌더링을 포함한 품질검증

문서 편집 시 별도 [`hwpx`](https://github.com/) 스킬과 함께 사용합니다. 이 저장소에는 배포 가능한 공식자료, 비식별화한 예시, 출처 목록만 포함하며 서명본·연락망·개인정보가 포함된 원본은 포함하지 않습니다.

## 사용 예

```text
$safekorea-hwpx와 $hwpx를 사용하여 2026년 공공기관 안전한국훈련
기본계획과 통합시나리오를 검토하고, 매뉴얼 불일치와 정량목표 보완사항을
붉은색 변경표시와 메모로 남긴 HWPX를 작성해 주세요.
```

## 자료 폴더

- `assets/official-guidance`: 공개된 행정안전부 가이드북·평가지표 설명자료
- `assets/templates`: 공식 빈 서식
- `assets/examples`: 비식별화한 예시 HWPX
- `assets/manuals-anonymized`: 재난유형별로 `위기관리 표준매뉴얼`, `위기대응 실무매뉴얼`, `현장조치 행동매뉴얼`의 3단계로 분류한 비식별 자료
- `references`: 근거 적용, 문서 작성, 정합성, 비식별화, 품질검사 기준
- `scripts`: HWPX 비식별화와 민감정보 검사 도구

원문이 갱신될 수 있으므로 실제 작성 전 공식 게시일과 개정일을 다시 확인해야 합니다.
