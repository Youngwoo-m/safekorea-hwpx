## 검토 근거

- 2026년 재난대응 안전한국훈련 기본계획 결재본: 2026년 8월 13일
- 2026년 재난대응 안전한국훈련 실행계획(안): 2026년 8월 18일 기준
- 2026년 안전한국훈련 통합시나리오: 2026년 8월 18일 기준

기본계획 원자료에 비공개 표시가 있어 원문 결재서, 내부 연락망, 인적사항, 기관·시설별 위치와 배치도, 사진, 실제 참여자·장비 명단은 게시하지 않았다. 샘플은 기관별 고유정보를 일반화한 대응절차와 작성 표를 제공한다.

## 적용할 때 확인할 사항

- 원자료에서 참여기관 수가 11개·14개·13개로 다르므로 최종 명단과 집계기준을 확인한다.
- 기상조건의 온도가 27℃·21℃로 다르므로 동일 상황조건으로 맞춘다.
- 상황판단회의 목표 15분과 시나리오 개최시점 H+20~30분을 대조한다.
- 사상자 분류와 신규·누적·이송 수치를 서로 확인한다.
- 교량 파손과 도로터널사고 표현의 혼재를 정리한다.
- 목표값은 계획상의 값이며 실제 성과나 보편적인 매뉴얼 기준이 아니다.
- 시나리오의 H+시간은 가상 경과시간이고 실행계획의 H+분은 실제 진행시간이다. 두 시간축의 연결표를 대상 기관별로 작성한다.

본문과 표는 한글에서 편집할 수 있다. 기초계획·실행계획·시나리오의 전체 제출용 서식을 대체하는 완성본으로 사용하지 않는다.
