# 근거자료 적용 우선순위

## 우선순위

1. 현행 법령
2. 해당 연도 행정안전부 안전한국훈련 기본계획·가이드북·평가지표
3. 승인된 위기관리 표준매뉴얼·위기대응 실무매뉴얼·현장조치 행동매뉴얼
4. 대상 기관의 최신 계획·조직·자원·연락체계 자료
5. 과거 컨설팅·평가보고서와 예시

## 충돌 처리

- 같은 항목이 다르면 시행일·개정일·승인일이 최신인 상위 근거를 적용한다.
- 기관 문서가 상위 매뉴얼과 다르면 임의로 맞추지 말고 불일치표에 기록한다.
- 표준·실무·행동매뉴얼의 역할 범위를 구분한다.
- 실제로 확인되지 않은 인원, 장비, 연락망, 도착시간, 성과는 `[확인 필요]`로 남긴다.
