# 재난유형별 위기관리 매뉴얼 분류

모든 재난유형은 다음 3단계로 관리한다.

1. 위기관리 표준매뉴얼
2. 위기대응 실무매뉴얼
3. 현장조치 행동매뉴얼

## 저장 구조

```text
assets/manuals-anonymized/
  [재난유형]/
    01_위기관리_표준매뉴얼/
    02_위기대응_실무매뉴얼/
    03_현장조치_행동매뉴얼/
```

## 분류 원칙

- 제목보다 작성기관의 법적 역할과 승인체계를 우선하여 단계를 판정한다.
- `위기대응 행동매뉴얼`처럼 비표준 명칭을 사용한 문서는 내용을 확인하여 실무 또는 행동매뉴얼로 분류한다.
- 동일 재난유형에 실무매뉴얼이 여러 개이면 관계기관별로 각각 관리한다.
- 개정안, 검토안, 승인본을 구분하며 승인본을 기준자료로 사용한다.
- 확보하지 못한 단계는 빈 폴더와 `STATUS.md`로 상태·필요자료·확인일을 기록한다.
- 저장소에는 공개자료 또는 비식별화·배포검토를 마친 자료만 넣는다.

## 현재 분류 대상

| 재난유형 | 표준 | 실무 | 행동 | 비고 |
|---|---|---|---|---|
| 풍수해 | 확보 | 미확보 | 확보 | 행동매뉴얼은 기관 고유정보 제거 필요 |
| 해양오염 | 확보 | 복수 확보 | 확보 | 관계기관별 실무매뉴얼 관리 |
| 해양재난 | 확보 | 확인 필요 | 확인 필요 | 상·하위 연계자료 추가 확인 |
| 산불 | 개정자료 확보 | 확인 필요 | 확보 | 최신 승인본 여부 확인 필요 |
| 지진 | 구버전 확보 | 구버전 확보 | 구버전 확보 | 최신본 확인 전 참고용 |
| 대형화산폭발 | 구버전 확보 | 구버전 확보 | 미확보 | 최신본 확인 전 참고용 |

위 표는 로컬 자료의 존재 여부이며 현행성이나 배포 가능성을 의미하지 않는다.
